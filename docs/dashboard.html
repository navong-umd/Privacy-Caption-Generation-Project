Privacy Caption / Policy Generation — PPG + ConvGNN

Given an Android APK, automatically generate an accurate, GDPR/CCPA-compliant, human-readable privacy caption → full privacy notice. Novelty: replace AST-path→BiLSTM captioning (code2seq / PriGen) with a Privacy Property Graph encoded by a relation-aware ConvGNN (RGCN) for multi-label Practice + Purpose classification.
